## Changes and causal controls

1. PrecommitHookTests previously copied source/ and .githooks/ without .gitattributes. Windows Git's system core.autocrlf=true then materialized staged text as CRLF, while the deterministic builder emitted LF. The real checkout's attributes specify LF and mark images as binary. The fixture now copies that file and sets fixture-local core.autocrlf=true so this condition is covered on every platform. The existing valid-case assertion also retains hook stderr on failure. Strict hook byte comparisons are unchanged.
2. ScreenshotAccess read UTF-8 JSON without an encoding. Native Python 3.13.15 with UTF-8 mode off uses CP1252 on this device; non-ASCII text then differs from the original record. Its three JSON reads now specify encoding="utf-8". Website serialization and generated bytes are unchanged.
