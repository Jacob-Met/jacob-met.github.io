How I work

Methods.

How I handle data, credit and claims.

In labs

For team research I describe my part. The results belong to the lab. Participant data, confidential material and unpublished findings don’t go on this site.

With AI systems

I save the task, the tool actions, the output and the failures. A model grading its own work doesn’t count as an independent check.

In code

Tests, examples and known limits live in each repo. A passing test only shows that the tested thing works.

Credit

I use other people’s libraries and tools. Where a publication or collaboration has disclosure rules, I follow them.

Keeping it current

I update this site when projects change. If something here is out of date, it’s a bug.
