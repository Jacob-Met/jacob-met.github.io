CaptureSuite

Multimodal recording means several devices, each with its own software, and a session that has to be stitched together afterward. I lead the architecture and direction of CaptureSuite, which is meant to be one place to run that kind of session and come out with a single sealed package.

A long-running daemon keeps the clock and the session state. Each device lives in a separate worker plugin, written in C++ or Python, so adding a new sensor doesn't mean touching the core. There's a desktop interface for the operator, a simulator so it can be developed without hardware, and analysis jobs for quality checks and features that read the sealed packages.

If you want to poke at it, the quality-check engine runs on a small synthetic session with no hardware at all.

Windows-only for now. The repository is the place for setup, licensing and current limits.

CanvasPilot

Most Canvas integrations assume a personal access token, and many schools don't let students create one. I wrote CanvasPilot to work with the login you already have: you sign in once in a real browser, including SSO and MFA, and a small local broker makes API calls through that session. The cookies stay in the browser profile.

It covers courses, assignments, modules, files, discussions, the calendar and more, as a CLI and as an MCP server, with digests like a cleaned-up assignment brief. The tests run entirely against fixtures, and there's an offline demo that needs no Canvas account at all.

Use it only where your school's policies allow. Submitting work and taking quizzes through it are real actions.

uma-sim

Umamusume's career mode has a lot of interacting systems, and I wanted to see them laid out as code. uma-sim is my unofficial Rust engine for runs, events, races and scoring, with a browser interface, a CLI, a REST API and an MCP wrapper.

The race physics lives in its own clean-room crate. Tests and a calibration script keep the numbers honest against the constants the engine loads.

Unofficial fan software with no connection to the game's creators, and it won't match every live-game mechanic.
