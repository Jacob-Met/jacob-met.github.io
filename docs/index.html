Multi-agent Fan-out Engine

A small, sanitized Python reference core for planning independent work, recording dispatches, and routing by requested effort. Open the public repository

Question

How can a multi-part task be planned and dispatched while keeping dependencies, idempotency, and uncertain outcomes explicit? Read the project context

Approach

  1. Represent work as a validated dependency graph so downstream parts stay queued until prerequisites complete.
  2. Record each dispatch, stable idempotency key, route, state change, and reconciliation evidence in SQLite.
  3. Park an ambiguous submission as outcome_unknown and require external evidence before resolving it; do not replay it.
  4. Keep transport and authentication outside the reference core behind a Hub adapter protocol.

Boundary. The tests use an in-memory SQLite ledger and local fake adapter. The package makes no model-provider calls, remote-worker calls, production-capacity claim, dispatch-volume claim, or benchmark-scale claim. Scope and limits

Disclosure. The code and documentation were developed iteratively with AI assistance, then manually reviewed and exercised with the repository tests and local demo. Repository README

CaptureSuite offline QC path

An offline quality-control path runs over a copy of a bundled synthetic EMG/IMU mini-session and emits inspectable reports and a receipt without capture hardware or patient data. Open the public repository

Question

How can a reviewer inspect a quality-control workflow before connecting a device or personal dataset? Read the project context

Approach

  1. Copy the bundled synthetic mini-session to a caller-chosen new output directory.
  2. Check original-fixture and copied raw-source hashes before and after the QC run.
  3. Refuse an existing output path or output inside the source fixture rather than overwriting it.
  4. Emit HTML and JSON reports plus DEMO-RECEIPT.json with hashes and synthetic-fixture classification.

Boundary. The README states that this synthetic demo does not establish hardware performance, clinical validity, or full product readiness; CaptureSuite v1.0 targets Windows 10 21H2+ x64. No hardware performance or clinical validity is claimed here; this case summarizes public source behavior, not an independent test. Scope and limits
