Projects

CaptureSuite

When several sensors record the same experiment, keeping their data together is its own problem. I'm building CaptureSuite around that: Windows recording tools, plugins for different streams, and a session package that travels with the recording (project scope).

The quality-control demo walks through a generated recording; no hardware needed. It's a way to explore the pipeline, not a performance benchmark (limits).

CanvasPilot

Canvas has useful information spread across a lot of screens. CanvasPilot gives it a command-line and MCP interface, with a local browser-session bridge for gaps in the API (project scope).

The offline demo is synthetic and needs no Canvas account (demo code; limits).

TowerOps

A small air-traffic simulation for exploring a simple question: what should a system check before it acts? TowerOps makes those checks explicit. It's a toy environment, not an operational ATC system (project scope; demo code).

Workflow checks

I also built workflow-checks for the little things that get buried in paperwork: a utility bill that looks off, a freight charge worth checking, or a PT authorization deadline. Three small Python programs, each with a sample you can explore. The records are made up; the README explains how the demos work.
