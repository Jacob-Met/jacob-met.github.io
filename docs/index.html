Academic research

Team projects in university labs. I describe my part; the data and results stay with the labs.

Current

Movement & rehabilitation

Motion-capture data for gait and fall-risk research. I support participant sessions, prepare recordings for analysis, and repaired the lab’s gait-analysis workflow so bad input stops it instead of producing wrong numbers.

Public software

My own projects. Source, setup and known limits are on GitHub.

Research capture

CaptureSuite

Runs a multi-device research session, cameras and body-worn sensors, on one clock and seals it into a single package for quality checks and analysis. I lead its architecture: each device runs as its own plugin, so adding a sensor never touches the core.

Student tools

CanvasPilot

Canvas access for students who can’t create API tokens. You sign in once with your normal school login, and a local broker makes requests without handing your session to the program asking.

Research demo

TowerOps

A simulated air-traffic scenario: an AI agent can suggest an action, but code checks the scenario, the approval and the readback before anything changes in the simulation. It does not connect to real aircraft.

Unofficial fan software

uma-sim

A simulator for the career mode of the game Umamusume: runs, events, races and scoring, with a browser interface.

Independent AI systems research

Experiments running AI models on real tasks: whether several models beat one, how much context a task needs, and where they fail. Every run is recorded so a result can be checked later.
