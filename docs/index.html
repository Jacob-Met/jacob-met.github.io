CaptureSuite

Research software · Python and C++. GPL-3.0. Repository created 2026-09-03, last push 2026-09-29.

Windows-first multimodal research capture. A daemon owns the clock and session state, each device runs as a versioned worker plugin in C++ or Python, and a session is sealed into one package for quality checks and analysis. A simulator and a Lab Streaming Layer bridge let it run without vendor hardware.

Artifacts: Source and README · Synthetic QC demo, no hardware · License

CanvasPilot

Student tooling · Python. MIT. Repository created 2026-09-05, last push 2026-10-01.

A Canvas LMS command-line tool and MCP server for schools that disable API tokens: one login in a real browser, then a local session broker makes the REST calls. Fixture mode runs the tests offline.

Artifacts: Source and README · Offline demo

TowerOps

Research demo · Python, Strands Agents. MIT. Repository created 2026-09-14, last push 2026-09-15.

A synthetic air-traffic decision-support demo built for the AWS Agents for Humans challenge. An agent may propose an advisory; deterministic code checks conflict projection, state freshness, approval and readback before the simulated state changes, and writes a hash-chained audit log. Not operational ATC software and not connected to live aircraft.

Artifacts: Source and README · Deterministic demo

Workflow checks

Demo · Python standard library, pytest. Repository created 2026-10-04.

Three small proofs of concept for verification-first back-office checks: detention and chargeback evidence packets with a carrier invoice, rate confirmation and proof-of-delivery match; a physical-therapy authorization and visit-limit tracker; and a utility bill exception checker. Deterministic rules decide, anything uncertain goes to a person, and every decision is logged with file and row evidence. Synthetic data only; not deployed in any real operation.

Artifacts: Source and README · Freight packet demo
