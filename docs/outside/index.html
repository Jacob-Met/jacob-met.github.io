Every project

The mind is the way in. This is the same work as a list. Back to the mind

  1. Wildside First in-person hackathonA painted nature game that turns real places into living, explorable worlds — ecology, weather and wildlife rendered in a hand-painted style in the browser.
  2. Hamon EngineA Rust + wgpu game engine built for agent control: typed ECS commands, deterministic replay, native and browser targets.
  3. afterimageHand it scraps — a blurry clip, a few photos, a partial log — and it reconstructs what most likely happened, then tells you which single observation would settle the rest.
  4. Replay ForgeRebuilds a real basketball play in 3D from game footage, then lets you branch the replay and ask what-if — every frame tied back to source video.
  5. chronos-visionWatches ordinary video and forecasts where every object in the scene is going next — and which constraints will change.
  6. Spire of OctavesA vertical world of cities stacked on cities — go down to be born, go up to be remembered. Thirty-seven free stories across nine heights of the Spire, from the boiler-row Clans of Geargrave to the brine courts of the Salt Scriptoria, plus serials, a short novel on Royal Road, and a game in progress on the Hamon Engine.
  7. mechanismTrack selected points in machine footage, compare possible motion constraints, and test them against later frames.
  8. Phantom WindowTurns flat phone video into a window you can look around: estimated depth, tracked camera, cinematic parallax and novel views.
  9. CaptionverseCaptions placed in space beside whoever is speaking, with directional sound cues — accessibility that tells you who and where, not just what.
  10. DominoA causal digital twin for smart-home automations: reconstruct event chains, expose rule conflicts and timing races, and prove fixes by replay.
  11. synapseWalk around inside a live, running software system in XR — see processes and data move, reach in and change them.
  12. materialtruthLights a part from many controlled angles and reads the surface back, catching scratches and defects a single photo misses.
  13. Hamon model researchAgents running real experiments on new model architectures, representations and learning algorithms designed for clusters from the start.
  14. TasteTableAgentic weekly dining and outing planner for seniors and caregivers, grounded in Qloo taste signals.
  15. LedgerlyAgentic invoice and payout copilot for freelancers with a human approval gate.
  16. RecallWeaveBrowser-only adaptive learning toolkit: transparent Bayesian learner, interactive labs, lesson authoring.
  17. Pneumatic MRI simA deterministic Rust simulation of the control stack for an air-driven surgical robot that works inside an MRI scanner.
  18. TowerOps First hackathon submission ever · Sept 2026An air-traffic-control conflict-awareness demo where bounded AI agents flag converging aircraft on a live radar view — built in a weekend with Strands Agents.
  19. Hamon memory researchHow should an agent decide what to remember, revise or forget? Working prototypes, Python with a Rust core.
  20. Surgical ergonomicsTracking surgeons' posture, muscle load and heart rate during procedures, with a realtime demo — built for the Soangra Lab at UCI.
  21. ThresholdA doorbell that works for people who can't easily hear, see or reach the door: who's there, what they want, and a way to answer.
  22. Familiar MemoriesWhen a relative visits, it recognizes them and brings up the photos you share — with consent and revocation built in, for families living with memory loss.
  23. ScopeSignalEvidence-backed milestone checkout with deterministic PayPal Sandbox replay.
  24. workflow-checksEvidence-first back-office checks on synthetic data: freight detention, invoice audit, PT authorization, utility exceptions.
  25. CaptureSuiteWindows-first multimodal research capture: daemon, versioned worker plugins, sealed sessions, PySide6 operator UI.
  26. CanvasPilotAgentic Canvas LMS tooling: MCP + CLI, a stay-open SSO session broker, structured Canvas REST tools.
  27. testpilotGive it a code change; it writes the regression tests, runs them, and fixes the ones that break. Nebius × NVIDIA hackathon entry.
